# 三角之境 · Triangle Lands

以《薩爾達傳說：曠野之息》的「三角形理論」為核心的 three.js 地形探索原型。行動裝置優先，build 出來是純靜態檔。

## 執行

```bash
npm install
npm run dev      # 開發（--host，可用手機連同網段測試）
npm run build    # 輸出到 dist/，可直接丟到 GitHub Pages / Netlify / 任何靜態主機
```

## 操作

| 手機 | 桌機 |
| --- | --- |
| 左半邊按住拖曳：虛擬搖桿（在手指按下的地方出現） | WASD / 方向鍵 |
| 右半邊拖曳：轉動視角 | 滑鼠拖曳 |
| 跳躍按鈕（空中再按一次：展開／收起滑翔翼） | 空白鍵 |
| 衝刺按鈕（按住；滑翔時按住＝俯衝） | Shift |
| 推著搖桿走向岩壁：攀爬；攀爬中按跳躍：向上躍；向後推＋跳躍：跳離岩壁 | 同左（W / S + 空白鍵） |
| 「共鳴 / 遠眺」按鈕（走近古碑祭壇時出現） | E |
| 右上音效按鈕 | 點擊切換自然環境音 |

## 三角形理論與探索體驗

| 設計原則 | 實作 |
| --- | --- |
| **地形遮蔽視線**：三角形（山丘）擋住後方，走到頂點才「展開新視野」 | `terrain.ts`：ridged noise 山脈只在部分區域出現，中間形成谷地；小尺度起伏遮住近景。 |
| **近距離才浮現的古碑遺跡** | 每座「古碑」由三座傾立石碑與浮空晶體構成，隱於山霧與林間；需探索至一定距離內才會自霧中顯現並泛起微光。 |
| **「看見」本身就是獎勵** | `checkDiscovery()`：走近古碑且視線未被山丘遮擋時，伴隨輕柔風鈴聲跳出「林間浮現微光」，並記於方位羅盤。 |
| **地形是真的阻礙，路線有意義** | `player.ts`：坡度大於約 54° 的懸崖走不上去（會沿著崖邊滑行），緩坡只會變慢。 |
| **無需爬塔的自然共鳴與隨風俯瞰** | 踏上古碑石陣按下共鳴後，鏡頭隨風升空環繞俯瞰群山，接著大範圍散開周遭半徑 150m 的地圖迷霧；之後也可隨時再次「遠眺」。 |
| **迷霧手繪羊皮紙地圖** | `map.ts`：依六大地域施以水彩分色與等高線，僅以墨字標示已到訪過的地域名與已發現的奇景（未到訪處仍保有神祕感）；經過之處撥開小範圍迷霧，與古碑共鳴則大範圍展開。 |
| **程序化大自然環境音效** | `audio.ts`：純 Web Audio 即時合成微風、樹葉摩挲、湖岸水波、立體聲林間鳥鳴與各地域專屬調式泛音，隨地域、海拔、晝夜與水域動態變化。 |

## 六大地域 · 奇景 · 時景

島嶼劃分為六個自然過渡的地域，各有獨立的地形輪廓、地表岩層配色、水色、植被、草花、大氣粒子、霧光與音樂調式；初次踏入或隔段時間重返時會優雅浮現地域名與詩意副標。

| 地域 | 位置 | 地景與氛圍 | 奇景（看見即發現） | 時景（特定時辰駐足收錄） |
| --- | --- | --- | --- | --- |
| **翠野** | 中央（起點） | 起伏草原丘陵、晴朗花粉與夜螢 | 千年古櫻 | — |
| **西嶺石林** | 西 | 石灰岩石柱群、碧綠潟湖、低空流雲 | 天生橋 | 石林雲海（朝霞／晴晝登高） |
| **東崖赤谷** | 東 | 層疊紅砂岩台地、深切峽谷、風沙稀疏植披 | 古獸遺骨 | 赤谷夕照（夕陽） |
| **南湖楓渚** | 南 | 低地湖泊與湖心島、秋楓落葉、睡蓮與蘆葦 | 沉水古門 | 楓湖月影（星空） |
| **霧林** | 西南 | 圓潤丘陵、參天古木、深綠青濃霧、夜間發光蘑菇與孢子 | 千年神木 | 螢光之森（星空） |
| **北境雪原** | 北 | 全島最高雪峰群、低雪線、雪松飄雪、夜空極光 | 冰晶尖塔 | 極光漫北境（星空） |

## 玩法：攀、滑、乘風、收集

| 系統 | 內容 |
| --- | --- |
| **體力輪** | 跟隨角色的圓形體力條。衝刺、攀爬、躍升、滑翔、快速游泳都會消耗；耗盡後變紅，必須站在地面休息到全滿才能再用。 |
| **攀爬** | 走不上去的懸崖可以直接攀爬，抵達崖頂或稜線時自動翻上去。 |
| **三角滑翔翼** | 空中再按跳躍展開；按住衝刺俯衝加速。滑翔時鏡頭自動轉到身後、拉開 FOV、出現速度線與翼尖氣流。 |
| **上升氣流** | 白色風柱可把滑翔翼往上托。大山旁的谷地有天然氣流；每座古碑共鳴後，旁邊也會升起一道。 |
| **靈光（金色三角）** | 散落在步道、山巔、懸崖中段、湖心、草原與上升氣流頂端。連續拾取音階會一路往上爬；每 5 顆提升體力上限。 |
| **風之試煉** | 從山頂出發的光環賽道，要在時限內依序穿過所有光環，完成後可得到靈光。靠近過的試煉會在羅盤上標出。 |
| **古碑共鳴** | 除了繪製地圖，也會提升體力上限，並喚起附近的上升氣流。 |

## 結構

```
src/
  noise.ts        種子隨機數 + simplex noise（每次世界都一樣）
  biomes.ts       六大地域定義：平滑權重場、霧光氛圍、粒子風格與各區音樂調式
  terrain.ts      多地域高度場：六區地貌自然混合 + 地標平台；height() 與網格三角形一致
  cel.ts          曠野之息風格水彩卡通 shader：多地域地表／水體著色、動態晝夜與地域霧光、極光、雲海、夜光菌
  landmarks.ts    六大奇景（遠景地標與視線發現）與五大時景（特定地點＋時辰駐足收錄）
  world.ts        地形網格、天空、水、各區植被與水域植物 (InstancedMesh)、動態草花、雲層、極光、雲海、飛鳥、古碑祭壇
  player.ts       角色狀態機：地面 / 空中 / 滑翔 / 攀爬 / 游泳、體力、動畫（擺臂、壓縮伸展、傾斜轉彎）
  collectibles.ts 靈光、上升氣流、風之試煉光環賽道（依地形決定位置，每次都一樣）
  fx.ts           粒子系統：拾取閃光、落地塵土、水花、翼尖氣流、隨地域變化的環境粒子（花粉／落楓／風沙／孢子／雪花）
  input.ts        動態搖桿、拖曳視角、鍵盤、按住衝刺
  map.ts          迷霧羊皮紙地圖：六大地域水彩上色、等高線、墨字地名（僅顯示已訪地域）與奇景標記
  audio.ts        Web Audio 程序化自然環境音、各地域調式泛音與抵達／發現音效
  main.ts         遊戲狀態機 (title → play → cinematic / vista → map)、鏡頭、地域標題、存檔 (v2)
```

進度（已發現 / 已共鳴的古碑、已到訪地域、已發現奇景、已收錄時景、已探索迷霧軌跡、靈光、完成的試煉、看過的提示、位置、靜音設定）存在 `localStorage`（`triangle-explorer-v2`）。

## 效能

- 平面／平滑卡通著色 low-poly，地形單一 draw call，地域權重預烘焙為兩張小型 `DataTexture` 供地表與水體 shader 快速取樣
- 樹木、古木、發光蘑菇、睡蓮、蘆葦、岩石與飛鳥全部使用 `InstancedMesh`
- 單一 draw call GPU 環形大氣粒子，pixelRatio 上限 1.75
- 地域霧光與天空自然融合，行動裝置維持流暢幀率
