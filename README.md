# 三角之境 · Triangle Lands

以《薩爾達傳說：曠野之息》的「三角形理論」為核心的 three.js 地形探索原型。行動裝置優先，build 出來是純靜態檔。

## 執行

```bash
npm install
npm run dev      # 開發（--host，可用手機連同網段測試）
npm run build    # 輸出到 dist/，可直接丟到 GitHub Pages / Netlify / 任何靜態主機
```

## 操作

| 手機 | 桌機 |
| --- | --- |
| 左半邊按住拖曳：虛擬搖桿（在手指按下的地方出現） | WASD / 方向鍵 |
| 右半邊拖曳：轉動視角 | 滑鼠拖曳 |
| 跳躍按鈕 | 空白鍵 |
| 「攀爬」按鈕（靠近塔底時出現） | E |
| 右上地圖按鈕 | M |

## 三角形理論如何落實

| 設計原則 | 實作 |
| --- | --- |
| **地形遮蔽視線**：三角形（山丘）擋住後方，走到頂點才「展開新視野」 | `terrain.ts`：ridged noise 山脈只在部分區域出現，中間形成谷地；小尺度起伏遮住近景。 |
| **遠方地標是誘因** | 每座塔都有 90m 的光柱，`depthTest` 開啟所以會被山擋住；`fog: false` 所以一旦露出來，再遠都看得到。 |
| **「看見」本身就是獎勵** | `checkDiscovery()`：光柱第一次進到畫面，**且**跟鏡頭之間沒有地形遮擋時，跳出「遠方出現了光芒」，塔會被標在指南針上。 |
| **地形是真的阻礙，路線有意義** | `player.ts`：坡度大於約 54° 的懸崖走不上去（會沿著崖邊滑行），緩坡只會變慢。 |
| **登高 → 鳥瞰 → 下一個目標** | 塔頂啟動後鏡頭拉遠環繞，接著地圖以動畫揭開半徑 150m；塔的位置經過安排，從塔頂能看到下一座塔的光柱。 |

## 結構

```
src/
  noise.ts    種子隨機數 + simplex noise（每次世界都一樣）
  terrain.ts  高度場：noise + 手動放置的地標平台；height() 與網格三角形完全一致
  world.ts    地形網格、天空、水、植被 (InstancedMesh)、雲、Tower
  player.ts   角色模型與移動 / 坡度 / 游泳
  input.ts    動態搖桿、拖曳視角、鍵盤
  map.ts      羊皮紙地圖：預先算好等高線 + 陰影，由塔揭開的遮罩
  main.ts     遊戲狀態機 (title → play → climb → cinematic → map)、鏡頭、存檔
```

進度（已發現 / 已啟動的塔、位置）存在 `localStorage`。

## 效能

- 平面著色 low-poly，地形約 5 萬個三角形、單一 draw call
- 樹木 / 石頭全部 InstancedMesh
- 無即時陰影（角色用 blob shadow），pixelRatio 上限 1.75
- 線性霧 + 天空同色，遠景自然融入

## 下一步可以加的東西

- 收集品（藏在山頂、死角的「種子」），用同一套 line-of-sight 邏輯做「瞥見」提示
- 攀爬任意斜坡 + 體力條、滑翔傘（讓塔頂下來的那一刻變成探索）
- 地圖標記 / 望遠鏡
- 更多地標種類（巨樹、遺跡、奇岩）作為中距離的三角形誘因
