# △ 三角之境 · Triangle Lands

以開放世界地形設計的「三角形理論」為核心的 three.js **無文字（Wordless）** 探索遊戲。全作以幾何圖像、動畫紋章、光點軌跡、鏡頭語言與程序化自然音效傳達一切資訊，行動裝置優先，建置後為純靜態網頁。

## 執行與測試

```bash
npm install
npm run dev      # 開發伺服器（--host，可用手機連同網段測試）
npm run build    # TypeScript 檢查並輸出靜態檔至 dist/
npm run preview  # 預覽 dist/ 建置結果
npm test         # 執行 Playwright 行動端觸控防縮放回歸測試
```

推送至 `main` 分支時，[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 會自動建置並部署 `dist/` 至 GitHub Pages。

## 三角形理論與無文字探索體驗

| 設計原則 | 實作 |
| --- | --- |
| **地形遮蔽視線** | `terrain.ts`：ridged noise 山脈只在部分區域出現，中間形成谷地；小尺度起伏遮住近景，翻過山脊才展開新視野。 |
| **漸進式視線揭露與嫋嫋靈煙** | `world.ts`：未啟動「古碑」不再以硬性距離隱藏，而是自然融入地域霧氣並升起隨風搖曳的暖金靈煙與微塵；底座可藏於山坡後方、靈煙探出山脊，搭配 `210m` 視線與遠眺之眼發現機制引導探索。 |
| **「看見」與靠近本身就是獎勵** | `checkDiscovery()` / `updatePoiFocus()`：未受山丘遮擋且進入視線時，伴隨風鈴聲、星塵與光圈漣漪將幾何標記釘上頂部無文字羅盤；靠近古碑、奇景或試煉起點時，鏡頭會平滑拉近縮放（收斂 FOV 並聚焦望向地標）並浮現柔和暗角與銀幕取景感，奇景周圍亦飄散專屬微光粒子。 |
| **地形是真的阻礙，路線有意義** | `player.ts`：陡峭懸崖無法直接走上去（會沿崖邊滑行），必須規劃繞路、攀爬或乘風滑翔的路線。 |
| **三段式共鳴與隨風遠眺** | `main.ts`：踏上未啟動的古碑按下互動後，1) 體力輪直接在角色旁擴容並綻放綠光、2) 鏡頭升空環繞並望向剛喚醒的上升氣流柱、3) 自動攤開地圖以青色波紋散開半徑 150m 迷霧；之後可隨時以「遠眺之眼」再度升空俯瞰。 |
| **全面無文字介面（Wordless UI）** | 標題畫面僅以三角紋章與 6 顆進度晶體呈現（含兩段式確認重置鈕）；開局以操作剪影引導；遊玩時透過情境變形按鍵、高空滑翔／氣流浮空剪影、飛向 HUD 的光點、5 段式靈光升級環與「時景」四角取景框（駐足對齊時漸亮聚光）取代所有文字提示。 |
| **無文字迷霧羊皮紙地圖** | `map.ts`：依六大地域施以水彩分色與等高線，搭配手繪墨線羅盤玫瑰與即時標示旅人目前位置、面對方向及視線扇形；支援縮放至區域細節與拖曳平移（雙指縮放、雙擊、滾輪與右下圖示按鈕），僅在已到訪地域繪出赭墨「地域紋章浮水印」，並以朱紅四芒星與「手繪奇景小圖示」標記已發現的奇景；移動軌跡撥開小範圍迷霧，古碑共鳴則大範圍展開。 |
| **程序化大自然環境音效** | `audio.ts`：純 Web Audio 即時合成微風、樹葉摩挲、湖岸水波、立體聲鳥鳴、草／石／水腳步聲與各地域調式泛音，並包含近碑感應微鳴、試煉急促滴答、時景駐足共鳴弦音與全收集慶典樂音。 |

## 六大地域 · 奇景 · 時景

島嶼劃分為六個自然過渡的地域，各有獨立的地形輪廓、地表岩層配色、水色、植被、草花、大氣粒子、霧光與音樂調式。步入不同地域時不彈出額外視覺提示，讓景觀、霧色、粒子與環境音自然流轉過渡。

| 地域 | 位置 | 地景與氛圍 | 奇景（看見即發現） | 時景（特定時辰駐足收錄） |
| --- | --- | --- | --- | --- |
| **翠野** | 中央（起點） | 起伏草原丘陵、晴朗花粉與夜螢 | 千年古櫻 | — |
| **西嶺石林** | 西 | 石灰岩石柱群、碧綠潟湖、低空流雲 | 天生橋 | 石林雲海（非夜晚登高俯瞰） |
| **東崖赤谷** | 東 | 層疊紅砂岩台地、深切峽谷、風沙稀疏植披 | 古獸遺骨 | 赤谷夕照（夕陽） |
| **南湖楓渚** | 南 | 低地湖泊與湖心島、秋楓落葉、睡蓮與蘆葦 | 沉水古門 | 楓湖月影（星空） |
| **霧林** | 西南 | 圓潤丘陵、參天古木、深綠青濃霧、夜間發光蘑菇與孢子 | 千年神木 | 螢光之森（星空） |
| **北境雪原** | 北 | 全島最高雪峰群、低雪線、雪松飄雪、夜空極光 | 冰晶尖塔 | 極光漫北境（星空望向北方） |

## 玩法：攀、滑、乘風、晝夜與收集

| 系統 | 內容 |
| --- | --- |
| **體力輪** | 跟隨角色的圓形體力條。衝刺、攀爬、躍升、滑翔、快速游泳都會消耗；耗盡後變紅並出現螢幕邊緣暗角提示，必須站在地面休息至全滿才能再用。 |
| **攀爬** | 走不上去的懸崖可以直接攀爬，抵達崖頂或稜線時自動翻上去。 |
| **三角滑翔翼** | 空中再按跳躍展開；按住衝刺俯衝加速。滑翔時鏡頭自動轉到身後、拉開 FOV、出現速度線與翼尖氣流。 |
| **上升氣流** | 白色風柱可把滑翔翼往上托。大山旁的谷地有天然氣流；每座古碑共鳴後，旁邊也會升起一道。 |
| **晝夜與調時** | 6 分鐘完整晝夜循環（朝霞 → 晴晝 → 夕陽 → 星空），亦可按 `T` 或右上天象按鈕平滑切換時辰，探索極光、夜光蕈與五大時景。 |
| **靈光（金色三角）** | 散落在步道、山巔、懸崖中段、湖心、草原與上升氣流頂端。連續拾取音階會一路往上爬；每 5 顆填滿計數器外圍光環並提升體力上限（`+10`），山頂靈光還會觸發視野呼吸與下坡風絲。 |
| **風之試煉** | 從山頂出發的光環賽道，頂部以圓點列與倒數條顯示進度，穿過光環時射出導引下個光環的風絲，限時將至時響起急促滴答聲；完成後於終點升起金色光柱並現出獎勵靈光。靠近過的試煉會記於羅盤。 |
| **古碑共鳴** | 除了大範圍繪製地圖，也會提升體力上限（`+15`）並喚起附近的上升氣流。 |

## 結構

```text
src/
  noise.ts        種子隨機數 + simplex noise（每次世界都一樣）
  biomes.ts       六大地域定義：平滑權重場、霧光氛圍、粒子風格與各區音樂調式
  terrain.ts      多地域高度場：六區地貌自然混合 + 地標平台；height() 與網格三角形一致
  cel.ts          手繪水彩卡通 shader：多地域地表／水體著色、晝夜 Preset 與地域霧光、極光、雲海、夜光菌
  landmarks.ts    六大奇景（遠景地標與視線發現）與五大時景（特定地點＋時辰駐足收錄）
  world.ts        地形網格、天空、水、各區植被與水域植物 (InstancedMesh)、動態草花、雲層、極光、雲海、飛鳥、古碑祭壇
  player.ts       角色狀態機：地面 / 空中 / 滑翔 / 攀爬 / 游泳、體力、動畫（擺臂、壓縮伸展、傾斜轉彎）
  collectibles.ts 靈光、上升氣流、風之試煉光環賽道（依地形決定位置，每次都一樣）
  fx.ts           粒子系統：拾取閃光、落地塵土、水花、翼尖氣流、隨地域變化的環境粒子（花粉／落楓／風沙／孢子／雪花）
  input.ts        動態搖桿、拖曳視角、鍵盤、按住衝刺與行動端多指／雙擊防縮放攔截
  map.ts          無文字迷霧羊皮紙地圖：六大地域水彩上色、等高線、手繪地域紋章浮水印（僅顯示已訪地域）與奇景小圖示
  audio.ts        Web Audio 程序化自然環境音、各地域調式泛音與無文字互動／探索音效
  style.css       全螢幕畫布、無文字幾何 HUD、動畫紋章、取景框與觸控樣式
  main.ts         遊戲狀態機 (title → play → cinematic / vista → map)、鏡頭、無文字 HUD／特效、存檔 (v2)
tests/
  touch-zoom.spec.ts  Playwright 行動端（Chrome / Safari）觸控防縮放回歸測試
```

進度（已發現／已共鳴的古碑、已到訪地域、已發現奇景、已收錄時景、已探索迷霧軌跡、靈光、完成的試煉、看過的操作提示、位置）存在 `localStorage`（`triangle-explorer-v2`）；靜音設定存在 `triangle-explorer-muted`。

## 效能

- 平面／平滑卡通著色 low-poly，地形單一 draw call，地域權重預烘焙為兩張小型 `DataTexture` 供地表與水體 shader 快速取樣
- 樹木、古木、發光蘑菇、睡蓮、蘆葦、岩石與飛鳥全部使用 `InstancedMesh`
- 單一 draw call GPU 環形大氣粒子，pixelRatio 上限 1.75
- 半浮點 HDR 選擇性柔光 Bloom（`EffectComposer` + `UnrealBloomPass` + `AgXToneMapping`，含 NaN/Inf 防護）與 texel 對齊太陽陰影
- 地域霧光與天空自然融合，行動裝置維持流暢幀率
